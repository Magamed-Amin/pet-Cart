# Интернет-магазин (Marketplace)

Мой pet-проект — разработка backend интернет-магазина по типу Ozon.

Планирую создать серверную часть магазина, которая будет отвечать за пользователей, товары, корзину и заказы.

## Технологии

- Go
- PostgreSQL
- pgx
- net/http

## Что планирую реализовать

- [~] Регистрация и авторизация
- [ ] Личный кабинет
- [ ] Каталог товаров
- [ ] Поиск товаров
- [ ] Корзина
- [ ] Оформление заказов
- [ ] Управление товарами

## О проекте

Сейчас нахожусь на начальном этапе разработки. Начал с системы регистрации пользователей и подключения PostgreSQL. Дальше планирую постепенно развивать проект.
